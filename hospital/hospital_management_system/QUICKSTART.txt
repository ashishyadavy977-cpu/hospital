INSTALLATION STEPS:
==================

Step 1: Install Dependencies
   Windows: Open Command Prompt and run:
   pip install -r requirements.txt
   
   Mac/Linux: Open Terminal and run:
   pip3 install -r requirements.txt

Step 2: Run the Application

   Option A: Using Batch File (Windows)
   - Double-click: run.bat

   Option B: Using Shell Script (Mac/Linux)
   - Terminal: bash run.sh
   - Or: chmod +x run.sh && ./run.sh

   Option C: Manual Run
   - Windows: python app.py
   - Mac/Linux: python3 app.py

Step 3: Access the Application
   - Open your web browser
   - Go to: http://localhost:5000
   - Application is now ready to use!

TROUBLESHOOTING:
================

Issue: "Python not found"
Solution: Install Python from python.org

Issue: "Port 5000 already in use"
Solution: Change port in app.py (last lines)

Issue: "Cannot find modules"
Solution: Ensure pip install was completed successfully

Issue: "Database errors"
Solution: Delete hospital.db and restart app
