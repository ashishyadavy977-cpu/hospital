🐛 TROUBLESHOOTING QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

"Python not found"
  → Install Python from python.org with "Add to PATH" checked
  → Restart Command Prompt/Terminal

"Module not found"
  → Run: pip install -r requirements.txt (again)
  → Check requirements.txt is in project folder

"Port 5000 in use"
  → Edit app.py last line, change port=5000 to port=5001
  → Or close other applications using port 5000

"Database errors"
  → Delete: hospital.db
  → Restart app (database auto-recreates)

"Images won't upload"
  → Ensure file is: PNG, JPG, JPEG, or GIF
  → Check file size < 16MB
  → Verify folder exists: static/images/uploads
