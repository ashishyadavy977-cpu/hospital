3. INSTALLATION STEPS
==============================================================================

STEP 1: Navigate to Project Directory
────────────────────────────────────

Windows (Command Prompt):
  cd "C:\Users\[YourUsername]\OneDrive\Desktop\hospital\hospital_management_system"

Mac/Linux (Terminal):
  cd ~/Desktop/hospital/hospital_management_system

STEP 2: Create Python Virtual Environment (Optional but Recommended)
──────────────────────────────────────────────────────────────────

Windows:
  python -m venv venv
  venv\Scripts\activate

Mac/Linux:
  python3 -m venv venv
  source venv/bin/activate

STEP 3: Install Dependencies
──────────────────────────────

Windows:
  pip install -r requirements.txt

Mac/Linux:
  pip3 install -r requirements.txt

Expected Output:
  Successfully installed Flask-2.3.0 Flask-SQLAlchemy-3.0.0 ...

STEP 4: Verify Installation
───────────────────────────

Windows:
  pip list

Mac/Linux:
  pip3 list

Should show:
  Flask        2.3.0
  Flask-SQLAlchemy  3.0.0
  SQLAlchemy   2.0.0
  Werkzeug     2.3.0

6. TROUBLESHOOTING
==============================================================================

ISSUE: "Python not found" or "'python' is not recognized"
────────────────────────────────────────────────────────
Solution A: Add Python to PATH
  1. Download Python from python.org
  2. During installation, CHECK: "Add Python to PATH"
  3. Restart Command Prompt/Terminal
  4. Test: python --version

Solution B: Use full path
  Windows: C:\Python39\python.exe app.py
  Mac: /usr/bin/python3 app.py

ISSUE: "Permission denied" or "Access denied"
──────────────────────────────────────────────
Solution:
  Windows: Run Command Prompt as Administrator
  Mac/Linux: Use: sudo python3 app.py
             OR: sudo bash run.sh

ISSUE: "Port 5000 already in use"
────────────────────────────────
Solution 1: Change port in app.py
  Find last line: app.run(debug=True, host='0.0.0.0', port=5000)
  Change to: app.run(debug=True, host='0.0.0.0', port=5001)

Solution 2: Kill process using port 5000
  Windows: netstat -ano | findstr :5000
           taskkill /PID <PID> /F
  
  Mac/Linux: lsof -i :5000
             kill -9 <PID>

ISSUE: "ModuleNotFoundError: No module named 'flask'"
─────────────────────────────────────────────────────
Solution:
  Windows: pip install flask flask-sqlalchemy
  Mac/Linux: pip3 install flask flask-sqlalchemy

ISSUE: "Database locked" or "Database errors"
──────────────────────────────────────────────
Solution:
  1. Stop the application (Ctrl+C)
  2. Delete: hospital.db
  3. Restart the application
  4. Database will be recreated automatically

ISSUE: "Cannot upload images" or "File upload fails"
────────────────────────────────────────────────────
Solution:
  1. Ensure images are: PNG, JPG, JPEG, or GIF
  2. File size must be < 16MB
  3. Check folder permissions: static/images/uploads
  4. Try uploading different image file

ISSUE: "Website won't load" or "Connection refused"
───────────────────────────────────────────────────
Solution:
  1. Check if app.py is running (see output on terminal)
  2. Verify URL: http://localhost:5000
  3. Not https:// (unless configured)
  4. Check firewall settings
  5. Try different port (see "Port 5000 already in use")

ISSUE: "Forms not submitting" or "AJAX errors"
──────────────────────────────────────────────
Solution:
  1. Open browser Developer Tools (F12)
  2. Check Console tab for errors
  3. Check Network tab for failed requests
  4. Ensure JavaScript is enabled
  5. Clear browser cache (Ctrl+Shift+Delete)

ISSUE: "Mobile view not responsive"
───────────────────────────────────
Solution:
  1. Open DevTools (F12)
  2. Click mobile icon
  3. Try different device sizes
  4. Clear browser cache
  5. Refresh page (Ctrl+F5)
